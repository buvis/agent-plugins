## Checked-correct notes and engagement

- **StateStore, pinned `store.py` at `cf8be72`:**
  - **Matches the source:** the retained API, the six boundaries, the flock/NOFOLLOW/single-link checks, the bounded reads and the fsync-before-replace behaviour.
  - **Repair and CAS:** `_commit_pair` repairs the pair on failure. CAS uses `_check_revision`.
  - **Revision handling:** `transaction` sets `revision = current + 1` itself, so a candidate stored in the intent must carry revision old+1. The design is consistent with this.
  - **Create-only init:** this is done with `os.link` in `initialize`.
  - **Restore fence:** it does block the epoch rollback and credential resurrection that the earlier dispatch found. Only its reachability is in question, per finding 2.
- **Contract A (PRD 00018 and umbrella 00011):**
  - **Envelope and response:** the fields match exactly.
  - **Errors and CLI:** the seven error codes, the CLI suffixes and the argv match.
  - **Bundle:** the bundle keys and types match the PRD. Bootstrap returns a path and never a secret.
  - **Replay:** the replay semantics follow 00011 line 60.
- **Package facade, `plugin.json` and `validate.py`:**
  - **Manifest version:** it is 0.10.0, which is the source for `package_version`.
  - **Validator:** `scripts/validate.py` does not constrain a `controller/` directory, and `scripts/` is existing precedent.
  - **Unaffected by this PRD:** `export-policy.py` and the facade stay as they are.
- **Lost-ack walk-through (owner.acquire):**
  - **Operator rotation:** the operator rotates in place. A retry with the current file at a later epoch retrieves the original receipt using the historical envelope.
  - **No new mutation:** that path grants no new mutation authority. This holds.
- **Capacity arithmetic:**
  - **Sizes:** 14 MiB + 2 MiB = 16 MiB.
  - **Emergency growth:** at most two responses of 64 KiB plus two descriptors, far inside the reserve.
  - **Second reserve slot:** it is never usable, because the first clearing operation leaves no owner. This is harmless, and one slot would suffice.
