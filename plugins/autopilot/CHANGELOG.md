### Changed

- **autopilot**: relax the published controller schema so `owner.recover` accepts a non-empty `reconciled_job_ids` array, which the runtime already refused as rejected evidence rather than as an invalid request. `contracts/controller/workflow-v1.json` drops `maxItems: 0` from `recover_payload.reconciled_job_ids`, the `recover-nonempty-jobs` fixture now expects a valid request, and `contracts/controller-v1.json` carries the regenerated schema and fixture digests, so a pinned bundle must be re-pinned.

### Fixed

- **autopilot**: `--verify` works on a project root tracked by a bare repository with a separate work tree (`~/.claude` under `~/.buvis`). Pass `--git-dir` and `--work-tree` together; untracked files in that work tree no longer refuse the record as `dirty-tree`, and edits to tracked files still do. Before, every such run failed with `unsafe-artifact-path`, or with `dirty-tree` when the git context came from the environment.
- **autopilot**: align the published controller contract with the runtime validator it drifted from. `workflow.batch`, `workflow.work` and `workflow.recovery` now declare their real object shapes instead of `null`, the persisted `workflow.pause` key is declared, `workflow.tasks` and `workflow.jobs` validate each row instead of accepting any array under a length cap, a caller job spec requires its `source_digest`, `resource_digest` and `permitted_operations` keys while a stored row keeps them optional, and `job.next` is declared in the request envelope with a closed empty payload. A state the controller writes no longer violates its own published schema.
- **autopilot**: stop the codex hook asset from naming the Claude-only `${CLAUDE_PLUGIN_ROOT}` (each adapter now declares `PLUGIN_ROOT_EXPR`), and make the host probe take the recorded session id from a real `--record-session` run instead of its echoed prompt, check gemini invocation outcomes before session ids, report `delegation`, and separate `resource_escape` from `preparation_failed`.
- **autopilot**: stop the helper-map generator's successor check from failing open. Verification is skipped only when the git probe fails for a directory outside every repository, decided from the file system (`GIT_DIR` and `GIT_WORK_TREE` unset, no `.git` entry at or above it), never from git's wording. Every other probe failure, a probe that answers anything but `true` (such as a bare repository), an absent `git` executable, an unresolvable `package_revision` and an unreadable listed path are each refused with git's own message, read in the C locale, and an unresolvable revision is no longer reported as stale bytes. Every listed path is compared byte for byte.
- **autopilot**: stop the helper-map generator from writing a source-map row that contradicts itself. A row the successor receipt certifies no longer keeps acceptance statuses or prose claiming its delivery evidence is planned, pending or on hold, and keeps every authored sentence of its reason that makes no such claim, while a row the receipt does not list is left untouched.
- **autopilot**: apply the retained-staging budget on the two controller publishing paths that still bypassed it, so a `workflow.open` against existing state and a bootstrap reconciliation of a pending credential intent both refuse with `recovery_required` under orphan pressure instead of publishing a revision.
- **autopilot**: enforce the frozen request binding rule in the controller parser, so a request whose `workflow_id` is null is accepted only as a `workflow.open` at revision 0 with no actor or lease epoch, a bound request requires both, and a request carrying a `job_id` is refused as `wrong_binding` before admission.
- **autopilot**: retry the controller state-lock open on a transient missing-file error, so a legitimate concurrent initializer loses the compare-and-set cleanly instead of surfacing an I/O failure, with the symlink, hard-link and regular-file guards applied on every attempt.
- **autopilot**: record the refused non-empty reconciliation evidence rule in the frozen controller fixtures, and correct the controller provenance document, which denied that a runtime had been extracted or certified and left eleven mapped runtime checks without a target test.
- **autopilot**: bound retained controller staging, rollback, intent and state-publication temporaries to 64 files and 16777216 bytes, refusing a mutation with `recovery_required` before staging when either limit would be exceeded or a retained artifact is unsafe or unreadable. A path that stages new credential bytes counts them together with the retained files; a path that stages nothing counts the retained files alone, so a pending intent plus over-budget orphans also refuses its own reconciliation. The state store no longer deletes crash-orphaned publication temporaries.
- **autopilot**: finish interrupted owner credential cleanup after state publication, while rejecting missing precommit evidence and corrupt remaining files.
- **autopilot**: report the current durable revision when snapshots refuse pending credential intents, without reconciling them.
- **autopilot**: rotate owner leases and operator credentials recoverably, retaining exact receipt replay without restoring retired mutation authority.
- **autopilot**: restore transaction publication guard checks at every durability boundary, preserving exact state and backup rollback when evidence changes.
- **autopilot**: `--verify` accepts a relative `--project-root` again and judges it exactly as its absolute spelling, instead of refusing every output path it resolves with `unsafe-artifact-path`.
- **autopilot**: `--verify` proves both its log sink and its result-artifact sink openable before it spawns the child and judges each sink by the file it actually opened; when the spawn fails, an existing log and result artifact stay byte-identical and a log this run created is removed; it reports a sink open, write or close failure as its own controlled error with the child killed, stops the child's leftover processes when a sink fails late, and removes only a leaf it created; `--export-policy --out` refuses a reader-less FIFO instead of hanging and refuses up front where `O_NOFOLLOW` is missing; the log sink judges containment before it reads a Git pointer.
- **autopilot**: `--verify` removes only the result artifact that its own failed run created; a file that took the artifact's name during the run, a leaf that became a directory, or a parent that became a symlink is left untouched and never replaces the run's own reported failure.
- **autopilot**: after a failed result-artifact write or close, `--verify` empties (or makes unparseable) the written file wherever it was moved, and reports in its reason when even that fails. A write that failed before it began leaves an existing artifact's earlier record in place.
