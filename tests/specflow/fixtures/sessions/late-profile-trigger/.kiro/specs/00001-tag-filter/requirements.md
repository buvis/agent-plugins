# Requirements: Tag filter

Sources: .kiro/specflow/intake/processed/00001-tag-filter/

## Purpose

Let a reader filter the article list by one tag.

## Scope

A tag filter on the article list page.

## Requirements

### REQ-001: Filter by tag

Source: the idea

**User story:** As a reader, I want to pick a tag, so that I see only the articles with that tag.

#### Acceptance criteria

1. WHEN the reader picks a tag THE SYSTEM SHALL list only the articles carrying that tag.
2. WHEN the reader clears the filter THE SYSTEM SHALL list every article again.
